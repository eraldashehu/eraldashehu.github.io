# eralda.dev

My personal portfolio: a single, dependency-free HTML page with an animated canvas background, a project carousel with case-study popups, and a release-notes style career timeline.

## Run locally

Open `index.html` in a browser. No build step.

## Host it free on GitHub Pages

1. Create a repository named **eraldashehu.github.io**.
2. Upload `index.html` and this README.
3. In **Settings → Pages**, set the source to the `main` branch.
4. The site goes live at https://eraldashehu.github.io

## Host it free on GitLab Pages

1. Create a project on GitLab (any name, for example `portfolio`).
2. Upload `index.html` and `.gitlab-ci.yml`.
3. GitLab builds the site automatically. Find the address in **Deploy → Pages**.
