About Me

I'm a frontend developer who turns complex data and workflows into interfaces that feel simple to use.

I started my career at CARDO AI, a fintech company, where I grew from intern to frontend developer in three years. There I built dashboards, data tables and reporting views for financial data, where an unclear table or a misplaced number has real consequences. Working with React and TypeScript every day taught me to keep components well typed and easy to reuse.

Since 2024 I've been a software developer at TeamSystem, building features for enterprise software that businesses rely on to run their daily operations. I work closely with product, design and backend teams, turning requirements into screens that handle many users, many settings and a lot of data, and stay fast while doing it.

What I care about most: reusable components, code my teammates enjoy reading, and interfaces that make complex work feel simple.
